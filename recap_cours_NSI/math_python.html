1. Création de variables

Pour créer une variable qui te permettra de stocker et réutiliser un élément, il faut cette structure :

Structure : {nom_de_ta_variable} = {valeur}


    # Tu peux par exemple faire :

💡 Astuce : Choisis des noms de variables clairs ! vitesse plutôt que v, temperature plutôt que t.

2. Faire des opérations

Pour que tes variables interagissent, il te faudra des opérateurs. Tu as : + pour additionner, - pour soustraire, * pour multiplier, / pour diviser, % pour obtenir le reste de ta division, ** pour élever à une puissance


    x = 2
    y = 3

    z = x + y     # Addition → 5
    z = x - y     # Soustraction → -1
    z = x * y     # Multiplication → 6
    z = x / y     # Division → 0.666...
    z = x // y    # Division entière → 0
    z = x % y     # Modulo (reste) → 2
    z = x ** y    # Puissance (2 puissance 3) → 8

4. Les conditions

Parfois tu veux que ton programme fasse quelque chose seulement si une condition est remplie. Tu peux faire ça avec if, elif, else. Tu commences tes conditions avec if, puis continues avec elif si tu veux qu’il y ait une condition, sinon utilise else.

Structure : if {condition}:, elif {condition}:, else:

Les opérateurs de comparaison :

Pour comparer et différencier, tu vas utiliser :

  • == (égal)
  • != (différent)
  • > < >= <= (comparaisons)
  • and or not (opérateurs logiques)

    age = 18

    if age >= 18:           # si age est supérieur ou égal à 18
        print("Majeur")     # retourne: Majeur
    elif age >= 16:         # sinon si age est supérieur ou égal à 16
        print("Presque")
    else:                   # sinon (dans tous les autres cas)
        print("Mineur")

5. Les boucles finies (`for`)

Si tu veux qu'une action se répète un nombre de fois fini, utilise for i in range().

Structure : for {nouvelle_variable} in range({début}, {fin}, {pas}):


    # Boucle simple
    for i in range(4):         # répète 4 fois (i = 0, 1, 2, 3)
        print(i)               # retourne: 0, 1, 2, 3

    # Avec début et fin
    for i in range(2, 8):      # de 2 à 7 (8 exclu)
        print(i)               # retourne: 2, 3, 4, 5, 6, 7

    # Avec un pas
    for i in range(0, 10, 2):  # de 0 à 9 par pas de 2
        print(i)               # retourne: 0, 2, 4, 6, 8
        
    n = 10
    somme = 0

    for i in range(1, n + 1):
        somme = somme + i
        
    print(f"La somme des {n} premiers entiers est: {somme}")

6. Les boucles limitées (`while`)

Pour faire une boucle qui se répète tant qu'une condition est vraie, utilise while.

C'est pratique quand tu ne sais pas à l'avance combien de fois tu veux répéter.

Structure : while {condition}:


    x = 1
    while x < 10:    # tant que x est plus petit que 10
        x = x + 2    # on ajoute 2 à x
        print(x)     # retourne: 3, 5, 7, 9, 11

Ce qui se passe : Python vérifie la condition à chaque tour. Ici, tant que x est plus petit que 10, on continue. Dès que x devient 11, on s'arrête car 11 n'est pas plus petit que 10.

⚠️ Attention : Assure-toi que ta condition finira par devenir fausse, sinon ta boucle tournera à l'infini !

7. Les listes

Une liste te permet de stocker plusieurs valeurs dans une seule variable. Tu peux les créer avec des crochets [].

Structure : {nom_liste} = [valeur1, valeur2, valeur3]

pour ajouter un element a une liste, tu dois utiliser .append(). pour en retirer une : .remove()


    fruits = ["pomme", "banane", "orange"]
    nombres = [1, 5, 10, 15]

    print(fruits[0])           # retourne: pomme (le premier élément)
    print(nombres[2])          # retourne: 10 (le troisième élément)

    # Modifier la liste
    animaux.append("kiwi")     # ajoute "kiwi" à la fin
    animaux.remove("chien")    # enlève "chien"
    animaux[0] = "tigre"       # remplace le premier élément

⚠️ Important : Les listes commencent à l'index 0, pas 1 ! Donc le premier élément est [0], le deuxième [1], etc.

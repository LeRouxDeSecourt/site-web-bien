Commandes de Base Linux (Terminal)

Navigation dans les dossiers

  • cd : Change de répertoire
  • cd ~ : Retour au répertoire personnel
  • cd /chemin/vers/dossier : Aller dans un dossier précis
  • cd . : Rester dans le dossier actuel
  • cd .. : Revenir au dossier parent
  • cd ../.. : Revenir deux dossiers en arrière
  • pwd : Affiche le chemin absolu du répertoire actuel
  • ls : Liste les fichiers du dossier courant
  • ls dossier1 dossier2 : Liste les contenus de plusieurs dossiers (ex : ls images mes_docs)

Gestion des fichiers et dossiers

  • mkdir nom_dossier : Crée un nouveau dossier
  • touch nom_fichier : Crée un fichier vide
  • rm fichier : Supprime un fichier
  • rm -r dossier : Supprime un dossier et son contenu
  • rmdir : Supprime un dossier (doit être vide)
  • cp source destination : Copie un fichier ou dossier
  • mv source destination : Déplace ou renomme un fichier ou dossier
  • cat fichier : Affiche le contenu d'un fichier

Infos système et utilisateur

  • whoami : Affiche le nom de l'utilisateur connecté
  • passwd : Change le mot de passe de l'utilisateur courant
  • man commande : Affiche le manuel d'aide d'une commande
  • find /chemin -name "fichier" : Cherche un fichier dans l'arborescence

Exemples pratiques


            # Aller dans le dossier /home/max
            cd /home/max
            
            # Créer le dossier mes_docs dans le répertoire courant
            mkdir mes_docs
            
            # Revenir en arrière et aller dans elsa
            cd ../elsa
            
            # Lister les fichiers dans plusieurs dossiers
            ls /home/max/images photos_vac ski

Gestion des permissions

Types d'utilisateurs

Symbole Type d'utilisateur Description
u Propriétaire (user) La personne qui a créé le fichier ou en est propriétaire
g Groupe (group) Les utilisateurs appartenant au groupe associé au fichier
o Autres (others) Tous les autres utilisateurs
a Tous (all) Tous les utilisateurs (u+g+o)

Types de droits

Symbole Valeur numérique Droit Description pour fichiers Description pour répertoires
r 4 Lecture (read) Permet de lire le contenu Permet de lister le contenu (ls)
w 2 Écriture (write) Permet de modifier Permet de créer/renommer/supprimer
x 1 Exécution (execute) Permet d'exécuter Permet d'accéder (cd)

Commandes de gestion des droits

Commande Description Exemples
chmod Modifie les permissions chmod 751 NSI (notation absolue)
chmod go-r fichier (notation relative)
ls -l Affiche les droits actuels ls -l fichier.txt
chown Change le propriétaire chown utilisateur fichier
chgrp Change le groupe chgrp groupe fichier

Notation des droits

Notation absolue

Utilise un nombre à 3 chiffres (propriétaire, groupe, autres) :


            chmod 755 fichier  # rwx r-x r-x
            chmod 644 fichier  # rw- r-- r--
            chmod 700 fichier  # rwx --- ---

Notation relative

Permet d'ajouter (+) ou retirer (-) des droits :


            chmod u+x fichier  # ajoute exécution au propriétaire
            chmod go-r fichier # retire lecture au groupe/autres
            chmod a+r fichier  # ajoute lecture à tous

Points importants :

  • Seuls le propriétaire et root peuvent modifier les droits
  • Pour accéder à un fichier, besoin de droit x sur le répertoire
  • Pour lister un répertoire, besoin de droit r
  • Pour modifier un fichier, besoin de w sur le fichier et x sur le répertoire
